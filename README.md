# 자동 스페이스

게임 창에 스페이스를 일정 간격으로 눌러 주는 AutoHotkey v2 매크로입니다.
AUTO(T)가 꺼지면 다시 켜 주고, 문파 도움 아이콘이 뜨면 눌러 주고, 켜질 때 새 버전이 있으면 스스로 업데이트합니다.

## 받기

[Releases](../../releases/latest)에서 `AutoSpace.exe`만 받아 실행하면 됩니다.
`wincapture.dll`은 exe 안에 들어 있어서, 같은 폴더에 없으면 처음 켤 때 꺼내 놓습니다.
(exe 이름은 바꿔도 됩니다. 업데이트는 지금 이름 그대로 바꿔 끼웁니다.)

## 쓰는 법

- **켜기/끄기:** 버튼 또는 F8, 종료는 F10. 맨 위 띠가 초록(동작 중) / 주황(쉬는 중) / 회색(꺼짐)으로 바뀌고, 켜져 있으면 창 제목에도 "동작 중"이 붙습니다.
- **스페이스 - 누르는 간격(초):** 스페이스 누르는 간격. 아래 줄에 누른 횟수와 마지막으로 누른 때가 나옵니다.
- **AUTO 유지 - 확인 간격(초):** 이 간격마다 AUTO 버튼을 보고, 꺼진 것이 확실할 때만 T를 눌러 다시 켭니다.
  버튼이 안 보이거나 애매하면 아무것도 하지 않습니다. 게임 창이 가려져 있어도 되지만 최소화하면 확인하지 못합니다.
- **자동 문파 도움 - 확인 간격(초):** 이 간격마다 화면 왼쪽의 문파 도움 아이콘(주황 바탕 흰 주먹)을 찾고, 떠 있으면 클릭합니다.
  게임 창이 뒤에 있어도 누르지만, 게임이 실제 커서 위치를 읽기 때문에 누르는 순간 커서가 약 0.05초 그 자리로 갔다가 돌아옵니다.
  마우스 버튼을 누르고 있는 동안에는 기다렸다가 다음에 누릅니다.
- AUTO 유지와 자동 문파 도움 상자 아래 줄에는 마지막 확인 결과와 다음 확인까지 남은 시간이 나옵니다.
- **백그라운드:** 게임 창이 뒤에 있어도 동작합니다. 끄면 게임 창이 맨 앞일 때만 동작합니다.
- **업데이트:** 켜질 때와 30분마다 확인하고, 새 버전이 있으면 묻지 않고 바꿔 끼운 뒤 다시 켜집니다.
  켜져 있었으면 다시 켜진 뒤에도 그대로 동작하고, 간격과 체크 설정도 이어집니다. [업데이트 확인] 버튼으로 바로 확인할 수도 있습니다.

## 새 버전 올리기 (개발자)

0. 처음 한 번: `target.example.ahk`를 `target.ahk`로 복사해서 대상 창을 적습니다. `target.ahk`는 git에 올라가지 않습니다.
1. `자동스페이스.ahk`의 `APP_VERSION`을 올립니다 (예: `1.0.0` → `1.0.1`).
2. `릴리스.bat`을 실행하고 바뀐 점을 한 줄 적습니다.
   소스 커밋·푸시, exe 빌드, SHA-256 계산, GitHub 릴리스 생성까지 자동으로 합니다.

필요한 것: AutoHotkey v2 + Ahk2Exe, git, GitHub CLI(`gh auth login` 완료)

## 파일

| 파일 | 내용 |
|---|---|
| `자동스페이스.ahk` | 화면, 스페이스 누르기, AUTO 유지 |
| `target.example.ahk` | 대상 창 설정 예시 (`target.ahk`로 복사해서 사용) |
| `AutoCheck.ahk` | AUTO 버튼 켜짐/꺼짐 판정 (WGC 캡처, 안 되면 화면 픽셀), 모양 맞추기 |
| `IconCheck.ahk` | 문파 도움 아이콘이 떠 있는지 판정 |
| `Update.ahk` | GitHub Releases 업데이트 확인·검증·교체 |
| `wincapture.dll` | 가려진 창 캡처 ([thqby/ahk2_lib](https://github.com/thqby/ahk2_lib), MIT) |
| `빌드.bat` | 이 폴더에 `자동스페이스.exe` 빌드 (시험용) |
| `릴리스.bat` / `release.ps1` | 새 버전 릴리스 |
